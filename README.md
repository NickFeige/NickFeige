## 🎮 Game Development

<div align="center">

> *"Building worlds, one script at a time."*

</div>

Beyond web development, I enjoy building games with **Unity** and **C#**. Game dev strengthens core programming fundamentals — physics simulations, collision detection, state machines, and real-time performance optimisation are problems that make you a better developer everywhere.

| Project | Description | Tech |
|---------|-------------|------|
| 🔫 [Shooter Game](https://github.com/NickFeige/shooterGame) | 3D shooter with player movement, shooting mechanics & enemy AI | Unity · C# |

**Areas explored:**
- 🕹️ Player controller & input systems
- 🤖 Enemy AI behaviours
- 💥 Physics engine & particle effects
- 🎯 Collision detection & game state management
